Free LaTeX tools for education and research.

LatexDo is a nonprofit. We remove the practical barriers that stop students, researchers, reviewers and technical writers from using LaTeX with confidence.

01

Free writing tools

A free desktop app and open-source tooling for writing, previewing and compiling LaTeX. No subscription, and no closed publishing workflow.

It works on local folders with a local TeX installation, so authors keep control of their files while getting modern editing, diagnostics, PDF preview and SyncTeX navigation.

02

Documentation and onboarding

Many people are blocked by installation, compilation, bibliography, package and template problems before they can focus on their work. The app explains its own errors, and we publish plain-language guides.

Written for students, independent researchers, educators and contributors who need clear explanations rather than vendor-only product documentation.

Read the LaTeX errors guide
03

Research workflow support

Tools for review comments, rebuttal drafting, bibliography consistency, source-to-PDF navigation and automated checks that help authors prepare stronger papers.

Our research pages describe ongoing work on compiler diagnostics, knowledge graphs and AI-assisted writing, in public HTML pages anyone can evaluate.

04

Open-source community

The source code is on GitHub under an open-source license. Contributors report bugs, review implementation work, improve documentation, suggest features and help set the roadmap.

The association board reviews roadmap and governance questions so the project stays aligned with its educational and research mission.
