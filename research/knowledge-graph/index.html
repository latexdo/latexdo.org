Research / Knowledge graph

A map your bibliography can explain.

Trace a connection back to authors, titles, venues, or years—and see which references your manuscript actually cites.

01 / Inputs

Entries become nodes.

The application parses BibTeX entries and scans citation commands in the project’s TeX files. Each graph node carries the entry’s key, metadata, cited status, and number of connections.

02 / Relationships

Every edge has a reason.

Shared author, venue, year, and title-token overlap contribute configurable weights. Title similarity uses Jaccard overlap. Minimum weight and strongest-edge limits keep the graph readable.

03 / Interpretation

Related is a starting point.

Search, filters, and citation recommendations help navigate the library. Separate citation checks flag issues such as missing keys and duplicate entries. Graph connections describe metadata relationships; they do not establish scientific support.
