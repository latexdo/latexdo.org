Research / Compiler

From source to page. And back.

Follow the local build pipeline, then see how LatexDo turns compiler output into useful feedback.

01 / Build locally

A fresh folder for every job.

The Electron compile service resolves latexmk, selects pdfLaTeX, XeLaTeX, or LuaLaTeX, and writes artifacts into a unique .latexdo/build/job-… directory. Builds support cancellation and a timeout.

02 / Connect the output

Three outputs, three jobs.

The PDF becomes the preview. SyncTeX maps positions between the PDF and source. The build log is parsed for file-and-line errors, warnings, and layout issues.

03 / Explain the failure

Find the useful error in the noise.

Source analysis adds context, likely locations, and suggested fixes. Diagnostic ranking distinguishes a likely primary error from follow-on failures. These are heuristic explanations; the original log remains available.

Inside the implementation

Based on the desktop source reviewed at revision 4059a3d . File paths are relative to the application repository.

  • electron/latexDiagnostics.ts Explains and ranks diagnostics
