Vision

Make LaTeX work feel direct.

LatexDo exists to make technical writing, review, and publication work more open, inspectable, and practical for people who write with LaTeX.

Local-first writing

Authors should be able to keep their projects, sources, PDFs, references, and compile outputs under their own control when local work matters.

Practical research tools

LatexDo aims to connect editing, compilation, diagnostics, citations, review comments, and rebuttal work in one clear workflow instead of spreading paper state across disconnected tools.

Open collaboration

The project should grow through open-source development, transparent governance, and useful contributions from researchers, students, reviewers, and technical writers.

Roadmap

From desktop app to the full LatexDo Ecosystem.

LatexDo is moving in focused phases: make the desktop app strong, open the editor, connect the ecosystem, then bring the workflow to iOS and Android.

Now
01

Desktop app phase

Stabilize the local-first app so people can trust LatexDo with real paper projects before depending on any hosted service.

  • Local project folders, TeX files, BibTeX files, and assets stay under the author's control.
  • PDF preview, SyncTeX navigation, compiler diagnostics, and project settings become dependable.
  • Native builds for macOS, Windows, and Linux get clearer installation, updates, and release checks.
Next
02

Editor launch

Ship the web editor as a polished writing space for people who want to start from the browser without setting up a desktop environment.

  • Live source editing and PDF preview for fast writing sessions.
  • Citation, comment, review, and rebuttal workflows designed for research papers.
  • Clean import and export paths so users can move between web and desktop work.
Then
03

LatexDo Ecosystem

The ecosystem means connected LatexDo tools that share the same project context without locking users into one surface.

  • Desktop app, web editor, docs, store, AI tools, templates, updates, and community resources work together.
  • Templates, add-ons, compiler knowledge, and documentation can be discovered from the place where the user is working.
  • AI assistance supports diagnostics, writing checks, citations, and review tasks while keeping sources inspectable.
  • Community and association resources connect contribution, governance, donations, board information, and releases.
After
04

iOS and Android

Bring the paper workflow to phones and tablets for reading, lightweight edits, review, and project checks.

  • Read papers, inspect generated PDFs, and review comments on mobile devices.
  • Make quick fixes to source files, citations, and notes when a full desktop session is not needed.
  • Check project status, diagnostics, updates, and review tasks while away from the main workstation.
