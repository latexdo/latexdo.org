Install

Download LatexDo from the downloads page. It is free, needs no account, and runs on:

  • macOS Apple Silicon or Intel, as a .dmg.
  • Windows 64-bit, as an installer .exe.
  • Linux 64-bit, as an .AppImage.

First launch

LatexDo is not yet signed with an Apple or Microsoft developer certificate, so your computer may warn you the first time:

  • macOS Open LatexDo once, then go to System Settings → Privacy & Security and click Open Anyway.
  • Windows When SmartScreen appears, click More info, then Run anyway.
  • Linux Run chmod +x LatexDo-linux-x64.AppImage, then open the file.

The PDF builder

LatexDo compiles with a TeX distribution on your computer: MacTeX on macOS, MiKTeX or TeX Live on Windows, TeX Live on Linux. If none is installed, the setup assistant downloads and verifies one for you.

Updates

LatexDo checks latexdo.org for new versions and installs updates from inside the app, only when they are signed by LatexDo. After an update, What's New lists the changes.

Your first project

A LatexDo project is an ordinary folder on your disk. Nothing is uploaded and nothing is locked into LatexDo.

  • Open a folder you already work in.
  • Start from a template: article, research paper, lecture notes, Beamer slides, letter, report and more.
  • Import a Word document, Markdown, a searchable PDF or an Overleaf project. See Import and templates.

Choose the main .tex file and the engine (pdfLaTeX, XeLaTeX or LuaLaTeX), then press Compile. The PDF opens next to the source. Build files are kept apart from your sources.

Writing

  • Code or Visual Edit the LaTeX source, or switch to the visual view to edit the same file as formatted text.
  • Completions for commands, environments, \ref labels and \cite keys from your .bib files.
  • Sentence completion Pause while writing and LatexDo suggests the end of the sentence in grey. Press Tab to keep it; keep typing or press Escape to dismiss it.
  • Search the open file with Cmd/Ctrl+F, and every file with Cmd/Ctrl+Shift+F.
  • Previews Hover an equation to see it rendered; included figures preview inline.
  • Spelling and proofreading Built-in spell checking, with optional grammar checking through a LanguageTool-compatible server.
  • Dictation Speak a paragraph; speech-to-text runs on your computer.

Compile, PDF and errors

Click any sentence in the PDF to jump to the line that produced it, or go the other way from the source to the PDF.

When a build fails, Problems explains the error in plain language: what happened, where, and how to fix it, with a button to go to the line and, when possible, one that applies the fix.

AI assistant

The assistant is optional, and nothing in your paper changes until you approve it: every edit appears as a diff with Approve and Reject.

Choose where it runs

  • On this computer Download a LatexDo model once, then work offline.
  • Ollama Use the models you already run locally.
  • Your own provider OpenAI, Anthropic, Gemini, Mistral, Groq, DeepSeek, OpenRouter, or any OpenAI-compatible endpoint, with your API key.

Ask about your project

Type @ to attach a project file, or \ for a quick command:

CommandWhat it does
\fixCompiles and fixes every error, then compiles again to check.
\summarizeSummarizes the open document, section by section.
\outlineOutlines the whole project.
\rewriteRewrites the selection to be clearer and shorter.
\proofreadProofreads the open document.
\citeSuggests citations from your bibliography for the selection.
\checkRuns the built-in checks and suggests fixes.

Work on a selection

Select text and right-click: Reformulate with AI (Cmd/Ctrl+Shift+R) shows the rewrite as it is written, and Ask AI about Selection (Cmd/Ctrl+Shift+A) sends it to the chat. Escape cancels.

Citations

  • Search Crossref and OpenAlex from the editor (Cmd/Ctrl+Alt+C). Choosing a paper inserts \cite and adds the entry to your .bib file.
  • Citation manager Finds unused entries, duplicates and missing keys, and cleans them up.
  • Knowledge graph Shows how your references connect to your paper and to each other, and suggests related work.

Figures, tables and notation

  • TikZ canvas Draw shapes and arrows and get editable TikZ. Diagrams from draw.io can be converted too.
  • Table generator Type cells like a spreadsheet, paste from Excel or Sheets, set column alignment, and choose grid, booktabs or minimal rules.
  • Notation manager Lists every symbol in your paper with where it first appears, and flags undefined or conflicting notation.

Review and rebuttal

Reviewer mode opens any PDF for annotation: highlight, comment, strike and draw.

Rebuttal mode lists each reviewer comment and keeps your answer next to the manuscript, linked to the lines you changed. When you are done, LatexDo writes the response letter from your answers.

Git

Source Control works on the project's Git repository, or creates one.

  • Commit Review diffs, stage, commit, push, pull and sync. The assistant can suggest a commit message.
  • Branches Right-click a branch to check it out, merge it, rename it or delete it.
  • History The graph shows every commit; right-click one to branch, tag, cherry-pick or revert.
  • Blame Cmd/Ctrl+Alt+B shows who last changed each line.

Collaboration

Share an open project directly from your computer. Others join from the LatexDo welcome screen with your invite, you approve each newcomer and choose what they can do, and you can stop sharing at any time. The project stays on your disk.

Import and templates

  • Word .docx documents.
  • Markdown files.
  • Searchable PDF reconstructed as LaTeX.
  • Overleaf projects, from their .zip export.

New projects can start from templates for articles, research papers, lecture notes, Beamer slides, letters, reports and review responses. Extra content packs are in the store.

Troubleshooting

  • The app will not open See First launch.
  • "No TeX distribution found" Run the setup assistant from Settings to install the PDF builder, or install MacTeX, MiKTeX or TeX Live yourself and restart LatexDo.
  • A package is missing MiKTeX installs packages on demand; with TeX Live, run tlmgr install <package>.
  • The build fails Open Problems for an explanation of each error, or ask the assistant to \fix it. The LaTeX errors guide covers the common ones.
  • The AI does not answer Open AI settings and check the provider, the model and, for cloud providers, the API key.
  • An update did not install Download the latest version from the downloads page and install it over the current one; your projects are not touched.
  • Linux AppImage does not start Make sure the file is executable. On desktops that restrict user namespaces, update to the latest LatexDo.

Still stuck? Open an issue or contact us.

Privacy and your files

LatexDo needs no account. Projects stay in folders on your computer and compile on your computer. The local AI model and dictation work offline. If you connect a cloud AI provider, only the text you send to the assistant goes to that provider. See the privacy policy.

FAQ

Is LatexDo free?

Yes. It is free to download and use, open source under the MIT license, and built by a French nonprofit association funded by donations.

Does it work offline?

Yes. Writing, compiling, the local AI model and dictation all work without internet. Citation search and cloud AI providers need a connection.

Do I need LaTeX installed?

LatexDo uses the TeX distribution on your computer. If you have none, the setup assistant installs one.

Can I move my paper from Overleaf or Word?

Yes. Import an Overleaf project, a Word document, Markdown or a searchable PDF and keep working in LaTeX.

Is my paper uploaded anywhere?

No. Your files stay on your computer unless you choose to share a project or send text to a cloud AI provider.

Contributing

LatexDo is developed in public at github.com/latexdo/latexdo-desktop. Bug reports, ideas and pull requests are welcome.

Run LatexDo from source
git clone https://github.com/latexdo/latexdo-desktop.git
cd latexdo-desktop
npm install
npm run dev

Before opening a pull request, run npm run lint, npm run typecheck and npm test. To report a security issue, follow the security policy. You can also volunteer with the association.
